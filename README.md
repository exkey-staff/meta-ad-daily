# meta-ad-daily

Meta広告の実績を毎朝取得して、クリエイティブの効き方を見る。

## 2つの動き方

| | どこで動く | 何をする |
|---|---|---|
| **クラウド（毎朝）** | GitHub Actions（Linux） | 実績を取って、数字の画面を GitHub Pages に出す。Macの電源に関係なく動く |
| **手元（必要なとき）** | Mac | バナーをOCRしてLP本文と突き合わせる。macOS標準のOCRを使うのでMacでしか動かない |

毎朝見たいのは数字なので、クラウド側は数字だけ。「なぜ効いたか」を掘るときにMac側を回す。

## クラウド側（毎朝5時）

`.github/workflows/daily.yml` が毎日 20:00 UTC（＝日本時間 5:00）に動く。

必要なSecrets:

| 名前 | 中身 |
|---|---|
| `META_ACCESS_TOKEN` | Meta Marketing APIのアクセストークン |
| `VIEW_PASSWORD` | 画面を開くときのパスワード |

**数字はパスワードで暗号化してから Pages に置く。** 見かけのログインではなく、
パスワードが無いとブラウザが復号できないので、リポジトリやURLが公開でも中身は読めない。

## 手元側

`tools/README.md` を見る。
